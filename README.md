# Tip Calculator

Application Android de calcul de pourboire développée avec Kotlin et Jetpack Compose.

## Fonctionnalités

- Saisie du montant de la facture
- Saisie du pourcentage de pourboire
- Calcul automatique du montant du pourboire
- Option pour arrondir le pourboire à l'entier supérieur
- Interface réalisée avec Jetpack Compose
- Icônes pour les champs de saisie

##  Technologies utilisées

- Kotlin
- Android Studio
- Jetpack Compose
- Material 3

##  Exemple

Pour une facture de **101 €** avec un pourboire de **15 %** :

- Sans arrondi : **15,15 €**
- Avec l'option « Arrondir le pourboire » : **16,00 €**

## 🚀 Installation

1. Cloner le projet.
2. Ouvrir le projet avec Android Studio.
3. Synchroniser Gradle.
4. Connecter un appareil Android ou démarrer un émulateur.
5. Lancer l'application avec le bouton **Run ▶**.

##  Structure principale

```text
app/
└── src/
    └── main/
        ├── java/
        │   └── com/example/tipcalculator/
        │       └── MainActivity.kt
        └── res/
            └── values/
                └── strings.xml
